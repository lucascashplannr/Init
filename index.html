Cómo funciona

Tres pasos entre la idea y el primer commit.

  1. Describe el proyecto

    Un nombre, un tipo. Init se encarga del resto y solo hace las preguntas útiles.

  2. Init prepara la base

    Estructura de carpetas, archivos de configuración y dependencias básicas se generan de una vez.

  3. Tú programas

    El proyecto arranca, se prueba y se despliega sin pasos de puesta en marcha adicionales.
